# Day 4 - Salesforce Flow Builder

## What is Flow Builder?

Flow Builder is a Salesforce automation tool used to automate business processes without coding. It helps organizations create workflows, update records, send emails, and automate tasks efficiently.

---

# Types of Flows

## Screen Flow
A Screen Flow interacts with users using forms and screens. It is mainly used for collecting user input.

## Record Triggered Flow
A Record Triggered Flow runs automatically when a record is created, updated, or deleted in Salesforce.

---

# Automation Ideas for College Management System

1. Automatically send confirmation email after student registration.

2. Automatically generate student ID for newly registered students.

3. Automatically notify faculty when course seats are full.

4. Automatically send fee reminder before payment deadline.

5. Automatically update available seats after student registration.

# Manual vs Automated Process

## Manual Process
Staff manually checks student records and sends emails individually.

## Problems in Manual Process
- Takes more time
- Human errors may occur
- Delays in communication
- Difficult to manage large amounts of data

## Automated Process
Salesforce automatically checks records, generates student IDs, and sends confirmation emails using Flow Builder.

## Benefits of Automated Process
- Faster workflow
- Better accuracy
- Saves time and effort
- Improves efficiency

# Reflective Questions

## 1. Why do companies automate workflows?
Companies automate workflows to save time, reduce manual work, and improve efficiency.

## 2. What problems happen with manual processes?
Manual processes are slow, error-prone, and difficult to manage.

## 3. Difference between Screen Flow and Record Triggered Flow?
Screen Flow requires user interaction, while Record Triggered Flow runs automatically in the background.

## 4. Why is no-code automation powerful?
No-code automation allows users to automate tasks without programming knowledge.

## 5. When should automation be avoided?
Automation should be avoided for very small or highly complex tasks that require human decision-making.

## 6. How does automation improve consistency and productivity?
Automation performs tasks accurately and quickly every time, improving consistency and productivity.
